# 🎯 Sobre o Projeto

Este projeto é um sistema completo de gerenciamento de tarefas desenvolvido para o Tech Challenge. O objetivo principal é oferecer uma experiência intuitiva e acessível para organizar tarefas diárias, com foco em usabilidade, performance e design responsivo.

A aplicação oferece funcionalidades essenciais para organização pessoal, como:

- Criação e gerenciamento de tarefas com prioridades
- Sistema de subtarefas para decompor tarefas complexas
- Modos de visualização (Simplificado e Completo)
- Histórico de atividades
- Notificações e lembretes inteligentes
- Configurações de acessibilidade
- Tutorial interativo para novos usuários

Toda a estrutura foi desenvolvida com foco em acessibilidade, garantindo que usuários com diferentes necessidades possam utilizar a aplicação confortavelmente.

<br />

# ✨ Features

- **Gerenciamento de Tarefas:** Crie, edite, conclua e exclua tarefas com facilidade. Defina prioridades (Baixa, Média, Alta) e organize suas atividades.

- **Subtarefas:** Divida tarefas complexas em subtarefas menores e mais gerenciáveis, acompanhando o progresso de cada uma.

- **Modos de Visualização:** Alterne entre o modo Simplificado (foco no essencial) e o modo Completo (todas as funcionalidades) para adaptar a experiência às suas necessidades.

- **Histórico de Atividades:** Acompanhe todas as ações realizadas - adição, conclusão, edição e exclusão de tarefas. O histórico persiste mesmo após remover as tarefas.

- **Notificações e Lembretes:** Receba notificações sobre ações realizadas e lembretes automáticos para tarefas antigas, prioritárias ou abandonadas.

- **Configurações de Acessibilidade:** Ajuste tamanho da fonte, espaçamento, contraste e preferências de notificação para uma experiência personalizada.

- **Tutorial:** Guia passo a passo para novos usuários, apresentando todas as funcionalidades da plataforma.

- **Persistência de Dados:** Todas as tarefas, configurações e histórico são salvos localmente (localStorage e Cookies) para acesso contínuo.

# ♿ Acessibilidade

A aplicação foi desenvolvida com foco em acessibilidade, oferecendo:

- **Ajuste de Fonte:** Controle de tamanho, espaçamento entre linhas e letras
- **Contraste:** Opções de contraste normal, alto e escuro
- **Confirmação Extra:** Opção para ativar confirmação antes de ações destrutivas
- **Preferências de Notificação:** Controle sobre lembretes e notificações
- **Modo Simplificado:** Interface focada no essencial para usuários que preferem menos distrações
- **Tutorial Interativo:** Guia completo para novos usuários
- **Navegação por Teclado:** Todos os componentes são acessíveis via teclado

# 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando:

- [**Next.js**](https://nextjs.org/) - Framework React com SSR

- **ESLint** - Padronização de código
- **GitHub Actions** - CI/CD automatizado

# 🚀 Executando o Projeto

## 📋 Pré-requisitos

- [Node.js](https://nodejs.org/pt-br/download) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

<br />

## 📥 Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/Excalibur757/Tech-Challenge-5.git
```

### 2. Acesse a pasta do projeto

```bash
cd Tech-Challenge-5
```

### 3. Instale as dependências

```bash
npm install
```

# ▶️ Executando a aplicação

### Modo Desenvolvimento

```bash
npm run dev
```

Acesse:

```bash
http://localhost:3000
```

### Modo Produção

```bash
npm run build
npm start
```

### Executar Lint

```bash
npm run lint
```
